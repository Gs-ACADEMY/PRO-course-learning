# PRO03_1208 メモ帳（JavaScript・講師の見本）

動画課題「JavaScript：メモ帳アプリ（localStorage）」の講師の見本です。
12/8 のスライド 3・4（前回の課題から今日へ）と、素材 1208-1 で使います。フレームワークなしの HTML・CSS・JavaScript だけで書いています。

## 開き方

`index.html` をブラウザで開くだけです（ビルドもサーバーも要りません）。

| ファイル | 中身 |
|---|---|
| `index.html` | 画面（入力欄・ボタン・探す欄・一覧） |
| `memo.js` | 足す・消す・探す・直す。メモは localStorage（`memos`）に保存 |
| `style.css` | 見た目 |

- 足す：入力欄に書いて「足す」。新しいメモが一番上に出ます
- 選ぶ：一覧のメモを押すと選べます（赤い枠）。入力欄に、そのメモの文字が出ます
- 直す：選んだまま入力欄の文字を書き換えて「直す」
- 消す：選んで「消す」
- 探す：探す欄に打つたびに、その文字を含むメモだけに絞ります
- 閉じても残ります。空に戻すときは、開発者ツールの Console で `localStorage.removeItem("memos")` を実行してから再読み込み

## スライドで見せる所

- スライド 3：書いて、足して、閉じても残る（localStorage での保存まで）。画面とコードを並べた素材 1208-1 で見せます（10/13 に作成。画面は日付を 12/2〜12/4 に止めて 1 件ずつ足し、読み込み直した状態。コードは講師の PC の VS Code で `memo.js` を開いた実際の画面で、1〜51 行。today・escapeHtml・html の中身は畳んだ形）
  - 5 行目の `"#add"` の前の小さな四角は、VS Code が `#add` を色の番号（#AADDDD）と読んで出す色見本です。コードには関係ありません（出るかどうかは VS Code の設定や拡張機能によります）
- スライド 4：足す・消す・探す・直すのたびに、`list.innerHTML = html();` で一覧を書き換えています。`memo.js` の 4 つの処理は、スライドと同じ並び（`add.onclick` → `del.onclick` → `find.oninput` → `edit.onclick`）です

## わざと残している間違い（スライド 4 の「書き換え忘れ」）

`memo.js` の「直す」（`edit.onclick`）だけ、最後に一覧を書き換えていません。

```js
edit.onclick = () => {
  if (selected === -1 || input.value.trim() === "") return;
  memos[selected].text = input.value.trim();
  save();
  /* 書き換え忘れ */ // ← わざと残した間違い。ここに list.innerHTML = html(); がないので、一覧が古いまま
};
```

- 配列と localStorage は書き換わるのに、画面の一覧は古いままです（＝画面と中身がずれる）
- 再読み込みすると、直した文字が出ます。ほかのメモを押して選び直しても、一覧が作り直されて直った文字が出ます
- 直し方（1 行）：`/* 書き換え忘れ */` の所に `list.innerHTML = html();` を書く
