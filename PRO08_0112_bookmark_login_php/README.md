# PRO08_0112 ログイン付きブックマーク（PHP・講師の見本）

1/12 の①（素材 0112-1）で使う、`PRO07_0108_bookmark_php` にログインを足した講師の見本です。
**ログインした人なら、誰のブックマークも全部見えて、消せます。** 1/12 の①「ログインで分かったのは『誰か』まで。『何をしてよいか』はまだ」の材料です。

## 動かし方（PHP 8 の組み込みサーバー）

```bash
php setup.php      # アカウント 3 人とブックマーク 6 件を入れる（最初に 1 回）
php -S localhost:8000
```

http://localhost:8000/select.php を開くと、ログインの画面に戻されます（ログインしないと見えない）。
