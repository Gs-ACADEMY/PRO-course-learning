# PRO02_1201 じゃんけんゲーム（講師の見本）

12/1 の素材 1201-1 で使う、じゃんけん課題の講師の見本です。

## 開き方

`index.html` をブラウザで開くだけです。手のボタンを押すと、相手の手と勝ち負けが出ます。

## わざと残している間違い（12/1 のスライド 4 で使う）

`janken.js` の `play()` に、エラーの出ない間違いが 1 つあります。

```js
const me = button.dataset.hand;            // "0"（文字）
const cpu = Math.floor(Math.random() * 3); // 0（数字）
if (me === cpu) { ... }                     // 文字と数字なので、いつも false
```

- 同じ手を出しても「あいこ」にならず、「負け」と出ます（あいこの数は 0 のまま）
- 何回か遊ぶと、初めておかしいと気づきます（＝「動かしてから気づく」の例）
- 直し方の例：`const me = Number(button.dataset.hand);`

講義で見せるときは、同じ手が出るまで何回か押してください（3 回に 1 回くらい起きます）。
