# このフォルダは `.github` です

Cowork から PC には `.github` という名前のフォルダを書き込めないため、`_github` という名前で置いています。
GitHub のリポジトリにする前に、フォルダの名前を `_github` から `.github` に変えてください（このファイルは消してかまいません）。

- `workflows/ci.yml`：CI の設定（PR のたびに、型チェックとテストを自動で流す）
- `pull_request_template.md`：PR の説明のひな形（やったこと／AI に任せた所／自分で確かめた所）

台帳の履歴（`PRO07-14_0108-0212_daicho_history.bundle`）の中には、最初から `.github` の名前で入っています。
