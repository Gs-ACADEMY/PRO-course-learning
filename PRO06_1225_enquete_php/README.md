# PRO06_1225 アンケートアプリ（PHP・講師の見本）

12/25 の①（スライド 3・素材 1225-1）で使う、動画課題のアンケートアプリの講師の見本です。
フォームから送られた値を、受け取る・確かめる・保存する・返すの 4 つの仕事で扱います。4 つは `write.php` に、上から順に並んでいます。

## 動かし方（PHP 8 の組み込みサーバー）

```bash
php -S localhost:8000
```

ブラウザで http://localhost:8000/ を開きます（「答える」→「結果を見る」）。

- 回答は `data/enquete.csv` に 1 行ずつ足されます（1 件目を送ったときにできる）。最初は 0 件です。空に戻すときは、このファイルを消します
- XAMPP などで動かすときは、このフォルダを htdocs の下に置きます。保存のときに `Permission denied` が出たら、`data` フォルダに書き込みの許可を付けます

## 4 つの仕事の場所（write.php）

| 仕事 | 行 | 中身 |
|---|---|---|
| ① 受け取る | 4〜8 | `$_POST['name']` などで、送られた値を受け取る |
| ② 確かめる | 10〜20 | お名前が空でないか（`empty`）・メールの形（`filter_var`）・満足度が 1〜5 か。だめなら `$errors` に理由を入れる |
| ③ 保存する | 22〜26 | 確かめを通ったときだけ、`file_put_contents(…, FILE_APPEND \| LOCK_EX)` で `data/enquete.csv` の最後に 1 行足す |
| ④ 返す | 28〜53 | 結果のページ。うまくいけば「ありがとうございました」、だめなら理由と「入力にもどる」 |

- エスケープ（発表会の見る所）：画面に出す値は、すべて `h()`（`funcs.php`。中身は `htmlspecialchars`）を通しています。`read.php` の一覧と、`write.php` の「○○ さんの回答を保存しました」です。お名前に `<script>alert(1)</script>` と入れても、文字のまま出ます
- `funcs.php` には、`h()` と、値を CSV の 1 行にする `csv_line()`（`,` や `"` や改行が入っても崩れないように、`"` で囲む）があります

## 保存の書き方について（スライド 3・7 のメモ）

- この見本は、ファイル（`data/enquete.csv`）に保存します。G's の動画がデータベースに保存する書き方なら、③ と `read.php` の読む所を、動画に合わせて差し替えてください。講義の前に、動画のコードで確かめます
- スライド 7 の対応表は「ファイルに書く（例：fwrite）」です。この見本は `file_put_contents` で書いています。動画が `fopen`・`fwrite` なら、そちらに合わせてもかまいません（どちらも「ファイルに書く」）
- `LOCK_EX` は、2 人が同時に送っても、行が混ざらないようにするためのものです

## メモ

- 画面のフォームには、必須の印（`required`）をあえて付けていません。空のまま送ると、サーバーの確かめ（②）が働くのが見えます。画面のチェックの話は、テーマⅡで Next.js を使ってします
- 結果のページで再読み込みすると、同じ回答がもう 1 件入ります（二重送信。スライド 15）
- `read.php` の一覧には、メールアドレスを出していません（誰でも開ける一覧に、人のメールアドレスは出さない）
- `data/enquete.csv` は Git に上げません（`.gitignore`）。中は UTF-8 なので、Excel でそのまま開くと文字化けすることがあります（VS Code で開く）
- `data/enquete.csv` は、URL（http://localhost:8000/data/enquete.csv）でも開けてしまいます。公開する場所に置くなら、data フォルダを公開の外に出すなどの対策が要ります（2/12 のセキュリティ）
- 日時は日本の時間で残します（`funcs.php` の `date_default_timezone_set('Asia/Tokyo')`。XAMPP などは、そのままだと別の国の時間になることがある）
- PHP 8.4 では、`fgetcsv` の最後の引数（`''`）まで書かないと「Deprecated」が出ます（`read.php`）
- 10/11 に PHP 8.4 で確かめました（空で送る → 理由が出る／正しく送る → 保存されて一覧に出る／`<script>` は文字のまま出る）
