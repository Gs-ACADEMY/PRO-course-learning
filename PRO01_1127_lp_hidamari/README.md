# PRO01_1127 ひだまり写真館 LP（講師の見本）

11/27 の素材 1127-1、12/18 の素材 1218-1 で使う、LP 課題の講師の見本です。

- 架空のお店（ひだまり写真館）の紹介ページ。HTML と CSS だけで作っています
- スマホの幅（横 375px）でも崩れないように、`@media (max-width: 768px)` で並びを変えています
- **お問い合わせのフォームは、わざと送り先（action）がありません。** 送っても、内容はどこにも届きません
  - 11/27 の①「このページを見た人が問い合わせたくなったら、どこに届く？」の材料です
  - 講義の④' で、外のフォームサービスを埋め込むと届くようになります

## 開き方

`index.html` をブラウザで開くだけです（サーバーはいりません）。
スマホの幅は、開発者ツールのスマホ表示（横 375px）で見ます。

## ファイル

- `index.html` … ページの中身
- `style.css` … 見た目（スマホの幅の指定は一番下）
