# PRO04_1215 郵便番号から住所を出す見本（12/15 テーマⅠの実演と演習①）

12/15 の講義（応用の回。テーマⅠ「失敗に強く借りる」）の実演で使う見本です。演習①で受講生が作るものの答えにもなります。
12/8 のひな形（`PRO03_1208_next_hinagata`）に、次の 2 つを足しただけです。

- `components/ZipSearch.tsx`：郵便番号を入れて「探す」を押すと、住所を出す部品
- `app/zip/page.tsx`：その部品を置いたページ（http://localhost:3000/zip）

使う API は郵便番号検索API（zipcloud。https://zipcloud.ibsnet.co.jp/doc/api ）です。鍵も登録もいりません。
ブラウザから直接呼べます（応答に `Access-Control-Allow-Origin: *` が付く）。

## 10/25 に確かめた返り値

HTTP の番号は、どれも 200 です。失敗は中身の `status` と `results` に出ます。だから `res.ok` だけでなく、中身も確かめます。

| 入れた番号 | HTTP | 中身の status | message | results | 画面に出る文字 |
|---|---|---|---|---|---|
| 1000001 | 200 | 200 | null | 東京都・千代田区・千代田 | 東京都千代田区千代田 |
| 100-0001 | 200 | 200 | null | 1000001 と同じ | 東京都千代田区千代田 |
| 123 | 200 | 400 | パラメータ「郵便番号」の桁数が不正です。 | null | パラメータ「郵便番号」の桁数が不正です。 |
| 0000000 | 200 | 200 | null | null | 見つかりませんでした |
| 0600000 | 200 | 200 | null | 北海道・札幌市中央区・（空） | 北海道札幌市中央区 |
| （回線を切る） | — | — | — | — | つながりませんでした |

- 応答の Content-Type は `text/plain;charset=utf-8` ですが、`res.json()` で読めます
- 郵便番号は文字で持ちます。数値にすると先頭の 0 が消えて 6 桁になり（0600000 → 600000）、桁数が不正になります
- 利用規約（https://zipcloud.ibsnet.co.jp/rule/api ）：回数や時間の制限を設けることがある・予告なしに止まることがある・正しさの保証はない。出典の表示の決まりはない（10/25 に読んだ）

## 動かし方

```bash
npm install
npm run dev     # http://localhost:3000/zip
```

失敗の見せ方：`123`（桁が違う）・`0000000`（ない番号）を入れる。回線を切るのは、開発者ツールの Network で「オフライン」を選ぶ（終わったら戻す）。
